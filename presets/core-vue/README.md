# Набор «core-vue»

Дизайн-система и кит компонентов, собранные и обкатанные на живом продукте.
Копируются в прототип целиком и работают сразу.

**Стек:** Vue 3.5 · Vite 7 · Tailwind CSS 4 (`@theme static`) · Reka UI ·
Lucide. Без своей рисовки иконок, без чужих UI-китов поверх.

## Что внутри

```
design/     tokens.css (палитра + роли + метрика + утилиты), base.css, appearance.js
components/ ui/ — 50+ компонентов кита;  app/ — каркас: оболочка, сайдбар, палитра
lib/        chart.js (шкалы и формат чисел), plural.js (русское число словом)
scaffold/   package.json, vite.config.js, index.html, main.js
design-lint.py  проверка словаря: токены и классы
```

## Как поставить

```bash
mkdir -p prototype/src && cd prototype
cp -r <skill>/presets/core-vue/scaffold/{package.json,vite.config.js,index.html} .
cp -r <skill>/presets/core-vue/{design,components,lib} src/
cp <skill>/presets/core-vue/scaffold/main.js src/
cp <skill>/presets/core-vue/design-lint.py tools/
npm install && npm run dev
```

Дальше нужны свои `App.vue` и `router.js` — их пишет автопилот под задачу.

## Как поменять бренд

Три места, и больше нигде:

1. **Акцент** — `--p-accent`, `--p-accent-hover`, `--p-on-solid`,
   `--p-accent-quiet/-soft/-line`, `--p-focus`, `--p-selection` в `tokens.css`.
   Светлое значение и тёмное задаются в одной строке через `light-dark()`.
   **После замены пересчитать контраст**: акцент на панели ≥4.5:1, текст на
   сплошной заливке ≥4.5:1, кромка контрола ≥3:1. Галерея `/system` считает
   это в браузере — открыть и посмотреть, а не понадеяться.
2. **Гарнитура** — `--font-sans` и импорты в `main.js`. Проверить казахские
   глифы (ә ғ қ ң ө ұ ү һ і) по `cmap`, а не по `unicode-range`.
3. **Знак** — `components/app/BrandMark.vue` — один `<path>`. Имя продукта
   приходит пропом `brand` в оболочку.

Ничего больше трогать не нужно: в разметке нет ни одного литерала цвета,
компоненты ссылаются только на роли.

## Правила, без которых набор разваливается

1. **Два яруса цвета.** Литералы — только в `--p-*`; в разметке доступны
   роли `--color-*`. Класса `bg-white` не существует: тёмная тема сделала бы
   его ложью.
2. **Тёмная тема одним объявлением** — `light-dark(светлое, тёмное)`.
   Вторая копия чисел запрещена.
3. **Контраст несёт то, что опознаёт контрол.** У кнопки с подписью — сама
   подпись, поэтому кромка волосяная. У пустого поля опознавать нечего —
   кромка 3:1 обязательна.
4. **Нажатие ощущается у всего нажимаемого** — утилита `press`.
5. **Фокус — одно кольцо.** У контрола со своим ребром фокус утолщает ребро;
   у ссылки и строки — отдельное кольцо.
6. **Вкладки только с панелями.** Полоска без `role="tabpanel"` — не вкладки,
   а переключатель: тогда `UiToggleGroup`.
7. **У графика обязана быть таблица** `sr-only` с теми же числами.
8. **Ничего не выдумывать** — непроверенное помечается `SlotNote`.
9. **Компонент, который живёт только в галерее, — долг.** Сделал — применил.

## Что проверять после сборки

`python3 tools/design-lint.py` — словарь. Браузерный аудит из
`scripts/audit.mjs` — поведение. Оба обязательны: линтер не поймал ни один
из семи дефектов поведения, найденных при обкатке набора.
