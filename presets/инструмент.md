# Пресет «Инструмент»

Для рабочего кабинета: плотно, тихо, много данных на экране. Человек проводит
здесь день, поэтому интерфейс не должен требовать внимания — его забирают
данные.

## Цвет — два яруса

Палитра объявляет роли; в разметке доступны **только роли**.

```css
:root {
  /* грунт и поверхности */
  --p-canvas:  light-dark(#ffffff, #151515);
  --p-raised:  light-dark(#ffffff, #1a1a19);
  --p-surface: light-dark(#f4f5f7, rgba(255,255,255,.05));
  --p-surface-2: light-dark(#eef1f2, rgba(255,255,255,.10));

  /* линии: в тёмной — белый с прозрачностью, он верен на любой ступени */
  --p-line:         light-dark(#e7e9ec, rgba(255,255,255,.10));
  --p-line-strong:  light-dark(#d8dcde, rgba(255,255,255,.14));
  --p-line-control: light-dark(#848d8e, rgba(255,255,255,.34)); /* ≥3:1 */

  /* текст: четыре ступени, не больше */
  --p-strong:    light-dark(#111827, #f0efec);
  --p-text:      light-dark(#111827, #f0efec);
  --p-text-soft: light-dark(#4b5563, #c3c2b7);
  --p-muted:     light-dark(#6b7280, #95938c);

  /* плашка «наоборот»: выделенное, тост, подсказка */
  --p-inverse:    light-dark(#111827, #ffffff);
  --p-on-inverse: light-dark(#f9fafb, #0b0b0b);

  /* акцент — подставить фирменный; здесь нейтральный синий */
  --p-accent:       light-dark(#2563eb, #7aa7f5);
  --p-accent-hover: light-dark(#1d4ed8, #93b8f8);
  --p-on-solid:     light-dark(#ffffff, #0a1733);
  --p-accent-quiet: light-dark(#eff6ff, rgba(122,167,245,.12));
  --p-accent-line:  light-dark(#bfdbfe, rgba(122,167,245,.32));

  --p-danger:  light-dark(#b8514a, #ec7e7e);
  --p-warning: light-dark(#a4682c, #db9300);
  /* текст НА мягкой подложке — отдельная роль: пара «состояние + его
     подложка» проваливает 4.5:1 чаще всего */
  --p-on-danger-soft:  light-dark(#ab4b45, #ec7e7e);
  --p-on-warning-soft: light-dark(#996129, #db9300);
}
```

## Метрика

| | Значение | Почему |
|---|---|---|
| Контролы | 28 / 36 / 44px, на тач 36 / 44 / 48 | shadcn 32/36/40, Ant small/middle/large, Material 32/40/48 — 36 в середине диапазона |
| Кегли | 12/16 · 14/20 · 16/24 · 20/28 · 24/32 | интерлиньяж кратен четырём, шкала Tailwind и Material |
| Ритм | 2 4 6 8 10 12 16 20 24 32 40 48 | всё кратно четырём, кроме двух мелких |
| Радиусы | 4 / 6 / 8 / 12 / 16 | выведены из 8 ± 4, как в shadcn |
| Движение | 100 / 150 / 250 / 400ms | нажатие · наведение · слой · перестройка |

Заголовок раздела 16px полужирный, не 24: в кабинете заголовков много, и
крупный кегль превращает экран в оглавление.

## Что запрещено

Градиенты · тени, кроме одной героической на экран · капсульные кнопки
(капсула = действие в витрине, в инструменте контролов десятки) · зебра в
таблицах · иконки собственной рисовки.
