# Пресеты

Готовые наборы токенов на случай, когда бренда ещё нет. Пресет — стартовая
точка, а не финал: акцент и имя всё равно подбираются под продукт, а контраст
пересчитывается после любой замены цвета.

| Пресет | Когда |
|---|---|
| [инструмент.md](инструмент.md) | рабочий кабинет: плотно, тихо, много данных |
| [витрина.md](витрина.md) | лендинг и маркетинг: воздух, крупный кегль, один акцент |

Оба построены одинаково: палитра объявляет роли, роли объявлены через
`light-dark()`, кегли идут с интерлиньяжем, метрика контролов — три размера.
Разница не в красках, а в калибровке: у инструмента контрол 36px и заголовок
16px, у витрины — 44px и 40px.
