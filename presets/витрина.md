# Пресет «Витрина»

Для лендинга и маркетинга: воздух, крупный кегль, один акцент. Задача —
довести до действия, а не показать данные.

## Отличие от «Инструмента»

Тот же скелет ролей, другая калибровка:

| | Инструмент | Витрина |
|---|---|---|
| Контрол | 36px | 44px, главный призыв 52 |
| Заголовок раздела | 16px | 32–40px (`clamp`) |
| Вертикальный ритм | 24px между блоками | `clamp(64px, 8vw, 120px)` между секциями |
| Радиус кнопки | 8px | капсула: кнопка одна и она зовёт нажать |
| Тень | почти нет | одна героическая под главным доказательством |
| Плотность текста | 14px, строка ≤68ch | 16–18px, лид ≤52ch по центру |

## Правила, которые дороже остальных

**Один акцент на экран.** Насыщенный цвет — на действии, подтверждении или
одном слове заголовка. Не для оживления блока.

**Узкая строка.** Заголовок ≤17 знаков, лид ≤52ch, `text-wrap: balance`.
Длинная строка в крупном кегле не читается, а сканируется по диагонали.

**Доказательство вместо обещания.** Скриншот продукта, цифра, имя клиента —
на месте абстрактной иллюстрации. Если доказательства нет, честнее пустое
место с пометкой, чем стоковая картинка.

**Форма говорит функцией.** Капсула — действие или статус. Прямоугольник со
скруглением — поверхность для чтения. Карточка-капсула и кнопка-прямоугольник
— ошибки, а не варианты.
