# designpilot

Навык Claude Code: собирает интерфейс по макету Figma, ссылке на живой
продукт или файлам — с дашбордом, дизайн-системой и обязательной проверкой.

**Версия 1.0** · 24.08.2026

## Что внутри

```

reference/            восемь этапов, каждый читается перед своим шагом
  00-приборы.md         дашборд и state.js
```

## Установка

В корне проекта:

```bash
npx skills add https://github.com/alibekpolatovmain/shai-designpilot --skill designpilot
```

Ставит в `.agents/skills/designpilot` и делает симлинк из `.claude/skills`,
так что навык видят и Claude Code, и другие агенты. Приватный репозиторий
тоже работает — по вашей git-авторизации. Флаг `-g` ставит глобально,
`--copy` — копией вместо симлинка.

Без интернета или вручную:

```bash
git clone https://github.com/alibekpolatovmain/shai-designpilot.git
cd shai-designpilot && ./install.sh
```

Навык самодостаточен: внешних зависимостей у самого навыка нет, нужен только
Python 3 для дашборда (он есть в macOS и Linux из коробки).
Для набора `core-vue` в прототипе понадобятся Vue 3.5, Vite 7, Tailwind 4,
Reka UI и Lucide — список в `presets/core-vue/scaffold/package.json`.

## Вызов

```
/designpilot ручной https://figma.com/design/…
/designpilot автопилот https://example.com/dashboard
/designpilot ./макеты
```

Без слова режима — **ручной**: молчание не согласие.

## Чем отличается от `autopilot`

`autopilot` строит проект от брифа до кода — «собери мне сервис».
`designpilot` занимается **интерфейсом**: разобрать вход, поставить
дизайн-систему, собрать экраны, проверить. Прогоны не пересекаются: один
пишет в `.autopilot/`, другой в `.designpilot/`.

## Откуда взялись правила

Каждое — из разбора живого продукта и из дефектов, которые нашлись при
сборке кабинета shainote. В частности, вывод, ради которого написан этап
проверки: **линтер проверяет словарь, браузер проверяет поведение**. Семь
дефектов — вкладки без панелей, безымянные флажки, контраст пары 4.39,
нереактивные данные, зависшее окно, столбики нулевой высоты, автозаполнение —
прошли линтер и нашлись только взглядом.
